# Homebrew formula

Source of truth for the formula lives here. Publish by copying to
[`latentmeta/homebrew-tap`](https://github.com/latentmeta/homebrew-tap) as `Formula/oratos.rb`.

Checksums for the current version come from the GitHub Release `SHA256SUMS` file.

```bash
# after creating the tap repo:
cp packaging/homebrew/oratos.rb /path/to/homebrew-tap/Formula/oratos.rb
```

Users:

```bash
brew install latentmeta/tap/oratos
```
